# EntityFrameworkCore.Encrypted.AwsKms

AWS KMS envelope encryption for [EntityFrameworkCore.Encrypted](https://www.nuget.org/packages/EntityFrameworkCore.Encrypted).

## Usage

```csharp
builder.Services
    .AddEncryption(x => x.UseAwsKms("arn:aws:kms:eu-west-1:123456789012:key/..."))
    .AddDbContext<AppDbContext>(x => x.UseNpgsql(connectionString).UseEncryption());
```

Mark properties with `[Encrypted]` or `IsEncrypted()` and add a migration for the `__EncryptionKeys` table.

## How it works

- A root key is generated by KMS on first start and stored wrapped in the context's own database
- Startup costs one KMS `Decrypt` per context (two with blind indexes); data keys are derived in memory, no KMS calls per value
- `RotateRootKeyAsync` rotates the root key, `RewrapRootKeysAsync` moves root keys to another KMS key
- The KMS client comes from dependency injection or the AWS configuration

IAM permissions: `kms:GenerateDataKey` (first start and rotation), `kms:Decrypt`, and `kms:ReEncryptFrom` / `kms:ReEncryptTo` for moving to another key.

Documentation: https://starushykart.github.io/ef-core-encryption

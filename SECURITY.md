# Policy

## Supported Versions

Entity Framework Core Encrypted supports the current major version only.
If issues or vulnerabilities are encountered with previous versions for which there is no workaround, upgrading to the latest version is recommended.

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

Please don't report vulnerabilities in public issues. Report them privately via [GitHub security advisories](https://github.com/starushykart/ef-core-encryption/security/advisories/new).
